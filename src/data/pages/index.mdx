# jbcom/pkgs

One tap. Every platform. Every `jbcom/*` project.

## Tap this repo

**Homebrew Formula** (macOS, Linux, WSL2+Linuxbrew)
```bash
brew tap jbcom/pkgs https://github.com/jbcom/pkgs
brew install <package>
```

**Homebrew Cask** (macOS)
```bash
brew install --cask <package>
```

**Scoop** (Windows)
```powershell
scoop bucket add jbcom https://github.com/jbcom/pkgs
scoop install <package>
```

**Chocolatey Source** (Windows)

Packaging sources are tracked here for reproducibility. A committed
nuspec does not guarantee that its version is live on the independent
Chocolatey community feed.
